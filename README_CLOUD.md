# スマホでワンタップ打刻（クラウド版）セットアップガイド

iPhoneやAndroidのホーム画面にあるボタンを「ポンっ」と1回タップするだけで、遠隔地のサーバー（GitHub）が代わりに日体大のシステムにアクセスし、自動で出勤/退勤の打刻を行ってくれるシステムを構築します。

休みの日はボタンを押さなければ良いだけなので、一番安全で確実な方法です！

---

## ステップ 1: GitHubで無料の「秘密の小部屋」を作る
クラウドの実行環境として、エンジニア御用達の **GitHub Actions**（無料）を使います。

1. [GitHub](https://github.com/) にアクセスし、アカウントをお持ちでない場合は作成（Sign up）します。
2. ログイン後、画面右上の「＋」アイコンから **[New repository]** をクリックします。
3. 以下のように入力して「Create repository」ボタンを押します。
   - **Repository name**: `timepro-auto` (何でもOK)
   - **Private**: 必ず「Private（非公開）」を選択してください（重要！）

## ステップ 2: プログラムのアップロード
作成したリポジトリ（小部屋）に、デスクトップにあるプログラムをアップロードします。

1. リポジトリ画面の **[uploading an existing file]** というリンクをクリックします。
2. デスクトップの `TimePro自動打刻` フォルダの中にある **`cloud_version`** フォルダを開きます。
3. その中にある **`auto_dakoku_cloud.py`** と、**`.github`** フォルダを、そのままブラウザ画面にドラッグ＆ドロップします。
4. 下の方にある緑色の「Commit changes」ボタンを押して保存します。

## ステップ 3: パスワードを金庫にしまう（シークレット登録）
プログラムの中に個人コードを直接書くのは危険なので、GitHubの「シークレット（金庫）」機能にあなたの個人コードとパスワードを保存します。

1. リポジトリ画面上部の **[Settings]** タブを開きます。
2. 左メニューの下の方にある **[Secrets and variables]** > **[Actions]** をクリックします。
3. 緑色の **[New repository secret]** ボタンを押し、以下の2つを別々に登録（Add secret）します。

   - **1つ目**
     - Name: `TIMEPRO_USER_ID`
     - Secret: あなたの個人コード（例：`118242`）
   - **2つ目**
     - Name: `TIMEPRO_PASSWORD`
     - Secret: 半角スペース1つ（キーボードでスペースキーを1回だけ押す）

## ステップ 4: スマホから命令するための「合鍵（トークン）」を作る
スマホからGitHubのプログラムを動かすための専用のパスワードを作ります。

1. GitHub画面の右上にある「自分のアイコン」をクリックし、一番下の **[Settings]** を開きます。
2. 左メニューの一番下にある **[Developer settings]** をクリックします。
3. 左メニューの **[Personal access tokens]** > **[Tokens (classic)]** をクリックします。
4. 右上の **[Generate new token]** > **[Generate new token (classic)]** を選びます。
5. 以下のように設定します：
   - Note: `スマホ打刻用` など
   - Expiration: `No expiration`（無期限）がおすすめ
   - Select scopes: **`workflow`** のチェックボックスにのみチェックを入れる
6. 下の緑のボタンを押すと、長〜い英数字のパスワード（`ghp_...` から始まるもの）が表示されます。**これをコピーして、iPhoneのメモ帳などに必ず保存してください（二度と表示されません）。**

---

## ステップ 5: スマホ（iPhone）のボタン作り
いよいよスマホ側の設定です。iPhone標準の「ショートカット」アプリを使います。

1. iPhoneで「ショートカット」アプリを開き、右上の「＋」で新規作成します。
2. 「アクションを追加」を押し、**「URLの内容を取得」** を検索して追加します。
3. 各項目を以下のように設定します：

   - **URL**: `https://api.github.com/repos/あなたのGitHubユーザー名/timepro-auto/actions/workflows/dakoku.yml/dispatches`
   - **方法**: `POST`
   - **ヘッダ**（「＞」を押して追加します）：
     - ヘッダ1: 
       - キー: `Accept` 
       - テキスト: `application/vnd.github.v3+json`
     - ヘッダ2:
       - キー: `Authorization`
       - テキスト: `Bearer ghp_先ほどコピーした長〜いトークン` （※Bearerとトークンの間は半角スペース）
   - **本文**: `JSON`
   - **本文の項目を追加（辞書/テキスト）**:
     - キー: `ref`
     - テキスト: `main`

4. ショートカットの名前を「打刻する」などに変更し、画面下から「ホーム画面に追加」を選びます。

🎉 **これですべて完成です！！** 🎉
ホーム画面に追加された「打刻する」ボタンを押すと、クラウド上のプログラムが動き出し、出勤・退勤を自動で判断して処理してくれます！
